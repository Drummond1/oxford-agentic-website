Four tools, two companies, and names that seem designed to be confused. Most comparisons of them are written by developers for developers, which is not much use if your working day is documents, spreadsheets and email rather than code.

This is the plain version, as the tools stand in September 2026. They change monthly, so treat anything about specific features as a snapshot and check each product's own page before you commit.

## The question that decides it

Ask what the job ends in.

- **A conversation, a draft, an answer.** The Claude chat app is enough. Most people already use it this way, and most people stop here.
- **A finished document, spreadsheet or file on your own computer.** That is what Cowork is for.
- **Working software.** That is Claude Code or Codex.

Almost every confusion between these tools comes from skipping that question and comparing feature lists instead.

## What each one is for

**Claude** is Anthropic's chat assistant, in a browser, a desktop app or on your phone. You ask, it answers, and you carry the result wherever it needs to go. Good for thinking, drafting and one-off tasks. It is not where multi-step work gets done on your behalf.

**Cowork** is Anthropic's agent for people who do not write code. It lives in the Claude desktop app and works on the files and folders on your own computer: give it a task, and it goes off and produces the finished document, deck or spreadsheet rather than a reply in a chat window. If your work is documents rather than code, this is the one to learn first.

**Claude Code** is Anthropic's agentic coding tool. It works across a whole codebase, reading files, making changes and running commands, and it began in the terminal before spreading into code editors and the desktop app. It is the developer's tool. Some non-developers use it anyway, because the same approach that builds software also builds quite serious automation, but it assumes you are comfortable working in a codebase.

**Codex** is OpenAI's agent. It started as a coding agent - in the terminal, in code editors, and in a cloud version you hand tasks to and check back on later - and OpenAI has since widened it beyond code. If your organisation lives in ChatGPT, it is the natural counterpart to the Claude tools.

## If you do not write code

Start with whichever agent comes with the subscription you already pay for. That is Cowork if you are on a paid Claude plan, and Codex if you are on ChatGPT. Switching subscriptions to chase a feature is rarely worth it: the differences between the leading tools matter far less than whether you have a workflow worth running in any of them.

Skip Claude Code until you have a reason. It is excellent, and it is the wrong first step for someone whose work does not end in software.

## The part that does not change

The tools will look different by next spring. What carries across all four is the part underneath: choosing a task worth automating, breaking it into steps that each do one thing, and deciding where [a human needs to stay in the loop](/guides/where-the-human-goes-in-an-agentic-workflow/). Someone who can do that picks up any new tool in an afternoon. Someone who learned one app's buttons starts again every time it changes.
