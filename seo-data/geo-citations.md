# Answer-engine citation log (GEO)

Each SEO/GEO cycle puts a rotating handful of real buyer questions to an answer engine and
records whether oxfordagentic.com appears, and what is cited instead. Rotate the questions;
do not re-run the same set every cycle. Engine: Perplexity search (ranked sources), unless
noted. These are snapshots, not rankings: results vary by engine, location and day.
